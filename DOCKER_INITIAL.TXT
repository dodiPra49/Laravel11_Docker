🚀 Cara Menjalankan
1.	Pastikan Docker Desktop di komputer Anda sudah aktif (ikon paus di taskbar Windows).
2.	Jalankan container dengan perintah berikut:
powershell
docker compose up -d --build
3.	Jalankan migrasi database Laravel:
powershell
docker compose exec app php artisan migrate
4.	Buka browser dan akses:
•	Laravel App: http://localhost:8080
•	phpMyAdmin: http://localhost:8081 (Server: db, User: laravel, Password: root)
